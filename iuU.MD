5. Shared screens and components
These should be reusable across applications wherever appropriate:
- Splash screen and loading states.
- Login and OTP components.
- Language selector.
- Light / Dark theme.
- Search and filters.
- Notifications.
- File and image upload.
- Empty states.
- Error and success screens.
- Confirmation dialogs.
- Permission-denied screens.
- Internet connection error.
- Profile and security components.
6. Important MVP boundaries
To avoid scope confusion:
- No inventory or warehouse screens.
- No stock quantity management.
- No multi-shop checkout initially.
- No supplier procurement module initially.
- No full accounting/ERP module.
- Dynamic forms and workflows will use controlled, supported configurations.
